# Math Quiz

A simple, interactive math quiz built with HTML, CSS, and vanilla JavaScript. Answer four multiple-choice questions and see your score as a percentage. If you get every question right, the quiz congratulates you; otherwise, you can try again.

## Features

- Four multiple-choice arithmetic questions
- Score displayed as a percentage, with a counting animation
- Retry prompt when one or more answers are incorrect
- Completion message when all answers are correct
- Responsive layout styled with Bootstrap and custom CSS

## Getting Started

No installation or build step is required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Select an answer for each question and click **Calculate**.
4. Review your score and try again if needed.
